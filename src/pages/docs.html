Packages

  • @anymirror/core

    The readers: a large file by ranges, a small file whole, a bundle by path; hints as a plugin.

  • veritiles

    Verified maps: a PMTiles Source, a MapLibre protocol for styles, sprites and glyphs, a script tag.

  • anymirror-pack

    The packer: makes the proofs a publisher uploads beside the content.

  • @anymirror/router

    The router contract: where a CID's bytes may live. Types only.

  • @anymirror/fisl-router

    A router over a FISL index.

Mirrored here
