Verified content over dumb hosts

Serve from any mirror. Trust only the bytes.

anymirror fetches files from any HTTP host — a CDN, an S3 bucket, GitHub Pages, a mirror nobody vouches for — and verifies every byte against a single CID before handing it over. A host can withhold bytes. It cannot alter one undetected.

How it works

Location is a hint. Identity is a hash.

  1. 01 · Pack

    One file in, one CID out.

    anymirror-pack writes a small proof beside your file — a descriptor and a tree of digests — and prints the anchor CID. That CID is the only thing your page has to trust.

  2. 02 · Publish anywhere

    Any host that speaks HTTP.

    Copy the file and its proofs to any static host. Publishing is cp; mirroring is rsync. Hints documents or a router tell readers where the bytes live.

  3. 03 · Verify on read

    Only the proofs you need.

    The reader fetches the proof pieces covering the bytes it reads and checks them up a sha2-256 chain to the CID. A tampered response fails, is counted, and the next host is tried.

One reader per shape of content.

  • VerifiedRaw

    One small file (at most 256 KiB), whole.

    {{reader:VerifiedRaw}}

  • VerifiedBundle

    Files by path from a bundle: glyphs, sprites, a site.

    {{reader:VerifiedBundle}}

  • VerifiedFile

    One large file, such as PMTiles or a video, by byte ranges.

    {{reader:VerifiedFile}}

Each behind its own entry point, so a page carries only the code it runs. No dependencies; WebCrypto is the only cryptography.

Small, strict, any size.

  • Fails closed

    Bad bytes are a VerificationError, never a render.

  • Mirror failover

    A host that serves tampered bytes is skipped for the next.

  • No dependencies

    WebCrypto is the only cryptography.

  • One request per warm read

    An exact Range request, the bytes an unverified client would fetch.

  • Any size

    Constant-size proof pieces, fetched as reads need them. No upfront download, no index.

  • Authenticated absence

    A bundle proves a path is missing, unlike a host's 404.

  • Locations are untrusted

    Hints and routers say where to look; a wrong location costs a request, never a wrong byte.

  • IPFS-compatible, not IPFS-dependent

    The packer can emit a UnixFS root and CAR so a gateway serves the same bytes.
