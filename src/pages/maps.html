Live

A map that checks every tile.

The small world map of the map demo, read from this site's mirror of it, with the demo itself as the next host: its tiles, style, glyphs and sprites, each checked against its CID before MapLibre draws it.

The map is Protomaps, and Protomaps is awesome: an open-source map stack on OpenStreetMap data that made PMTiles, the format that puts a whole tiled map in one file any static host can serve, and builds free basemaps and styles for it.

Loading the map fetches MapLibre and the map's files from this site, and the demo's hints document from GitHub Pages.
